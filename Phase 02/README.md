# Habito
This is the implementation of Habito





# Installation
This implementation relies on Rich, Pydantic and a few other major Python libraries.
To install them:
```shell
# Create a .venv
$ python -m venv .venv
# Activate the .venv
$ source .venv/bin/activate
# Install dependencies
$ pip install -r requirements.txt
```

## Running the application
The easiest way is to just run *`python3 main.py`*

## Importing sample data
The implementation supports the creation of data in the configured repository be specifying

```shell
# Import (test) data
$ python3 main.py 
```
