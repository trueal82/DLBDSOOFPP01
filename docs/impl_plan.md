# Main client

## Show todays habits

Should print a table of all habits, which are

- executionFrequency Daily, but have no execution today
- executionFrequency Weekly, but have no execution in the last days

## Add habit

guide the user through each field and create a habit object via service

## Mark habit done

- print the table of all habits with id
- ask for the id to execute
- 0 to exit
- ask for comment
- store the object

## Show history

- print a table of all habits
- ask for the id
- print all the executions for that habit

## Show all habits

- print a table of all habits

# CLI Client
